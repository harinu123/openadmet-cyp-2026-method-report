# OpenADMET CYP Challenge 2026 — harinu123 method reports

This repository documents the accepted submissions from **harinu123** to the
[OpenADMET CYP Inhibition Blind Challenge](https://huggingface.co/spaces/openadmet/cyp-challenge).

## Final reports

- [Time-dependent inhibition classification](CLASSIFICATION_METHOD_REPORT.md)
- [CYP3A4 protein–ligand structure prediction](STRUCTURE_METHOD_REPORT.md)
- [Public-only audit supporting the structure v15 switch](STRUCTURE_V15_PUBLIC_AUDIT.md)

The reports describe the final frozen methods, validation design, leakage and
leaderboard safeguards, limitations, and submission checksums. No proprietary
training data were used. Model and submission artifacts are retained privately;
this repository is a methods report, not an open-code release.
