# OpenADMET CYP3A4 structure-prediction method report

This repository documents the final **harinu123** submission to the
[OpenADMET CYP Inhibition Blind Challenge](https://huggingface.co/spaces/openadmet/cyp-challenge)
Structure Prediction track.

## Method report

- [CYP3A4 protein–ligand structure prediction](STRUCTURE_METHOD_REPORT.md)

The report describes the frozen candidate-generation and selection pipeline,
the single mechanism-guided correction used in the submitted archive,
public-only validation, leakage safeguards, physical and stereochemical release
gates, limitations, and the exact artifact checksum.

No proprietary training data were used. The source poses, validation records,
and submission artifact are retained by the participant and can be supplied to
the organizers if requested. This repository is a method report and does not
make an open-code claim.

Report frozen: 2026-11-03.
